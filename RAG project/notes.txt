# Software Engineering – Notes

## Definition

Software Engineering is the systematic approach to designing, developing, testing, deploying, and maintaining software applications.

---

## Objectives of Software Engineering

* Develop high-quality software
* Reduce development cost
* Deliver software on time
* Improve maintainability
* Increase reliability and performance

---

## Software Development Life Cycle (SDLC)

### 1. Requirement Analysis

Collect and analyze user requirements.

### 2. System Design

Create architecture, UI design, database structure, and system planning.

### 3. Development

Write code and build application features.

### 4. Testing

Identify and fix bugs using different testing methods.

### 5. Deployment

Release software to users.

### 6. Maintenance

Update software and resolve issues after deployment.
